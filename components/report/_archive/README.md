# Archived report components

Unused legacy report UI components archived during the safe-capture refactor.

These files are **not** part of the live report tree. Production report rendering uses `ReportView` and its children only. Do not import from this folder in active report paths unless you are intentionally restoring a legacy layout.

Archive criteria: components that were no longer referenced by the live ReportView tree after the capture/evidence refactor, kept here for reference rather than deleted.
